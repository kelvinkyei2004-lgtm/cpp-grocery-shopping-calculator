# Grocery Shopping Calculator (C++)

## Overview

This project is a console-based grocery shopping calculator developed in C++. The program allows users to enter purchased items, choose available discount offers, and calculate the final cost including discounts and sales tax.

This project was completed as part of CIS 1111 coursework.

---

## Features

- Enter customer information
- Calculate item subtotal based on price and quantity
- Apply different discount options:
  - Buy One Get One Free (BOGO)
  - 5% discount
  - Custom discount selection (1-5%)
  - Account holder discount (10%)
- Calculate sales tax
- Display final purchase summary
